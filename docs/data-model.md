# Data Models

The relational database houses the core domain structures:
- `User` & `Role`: IAM schemas.
- `Pipeline` & `PipelineRun`: Configuration and runtime logs of ETL pipelines.
- `Dataset` & `DataSource`: Metadata schemas of incoming formats.
- `QualityRule` & `Metric`: Constraints on columns/records and telemetry aggregates.
- `Anomaly` & `Investigation`: Detected alerts and human workflow lifecycle.
- `MLPrediction` & `AIAnalysis`: Insights generated by ML/LLM engines.
